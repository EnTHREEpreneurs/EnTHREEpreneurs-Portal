Welcome, admin.

Use the menu to maintain the shared EnTHREEpreneurs portal. Content is stored in Supabase Postgres and uploaded files are stored in Supabase Storage.

Admin permissions

Owner, President, and Vice President can manage class content. Only the Owner can manage the admin roster.

File uploads

Learning resources, activity attachments, class-fund receipts, and event posters can be uploaded directly to the class-files Supabase Storage bucket. External links are also supported.

For best reliability, keep individual uploads reasonably sized; Supabase recommends standard browser uploads for smaller files and resumable uploads for files above roughly 6 MB.
